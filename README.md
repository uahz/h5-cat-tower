# 🐱 猫咪叠叠乐 · Cat Tower

一个零依赖、单文件的 H5 物理小游戏。用自写的 Verlet 物理引擎，把一只只软萌小猫叠到高台上——别让它们掉下去！

## ✨ 玩法

- 移动鼠标 / 手指，瞄准高台上方。
- 点击 / 松手，把当前小猫投放下去。
- 小猫之间、小猫与高台之间会自动产生物理碰撞与支撑。
- 叠得越高分越高；小猫掉出平台即结束。
- 最高分自动保存在浏览器 `localStorage`。

## 🎮 特点

- **纯前端单文件**：HTML + CSS + JS 全部内联，零依赖、零构建。
- **自写物理**：Verlet 积分 + 多次约束迭代，丝滑稳定的堆叠手感。
- **高帧率**：固定步长 120fps 循环（accumulator 模式），动画顺滑。
- **可爱视觉**：Pastel 马卡龙配色，球体渐变 + 眨眼 + 腮红。

## 🚀 运行

直接双击 `index.html` 用浏览器打开即可；或挂到任意静态托管（GitHub Pages / Vercel / Nginx）。

```bash
# 本地起一个静态服务器
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 📱 适配

- 画布 390 × 720，DPR 自适应（≤3），手机端竖屏体验最佳。
- 支持鼠标与触摸。

## 🛠 技术栈

| 项目 | 说明 |
| --- | --- |
| 渲染 | Canvas 2D |
| 物理 | 自写 Verlet（重力 / 摩擦 / 圆形碰撞 / 支撑约束） |
| 主循环 | `requestAnimationFrame` + 固定步长 |
